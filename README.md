# PostgreSQL Slow Log Parser (Python + Linux)

Утилита командной строки для автоматизации анализа логов PostgreSQL. Разработана для выявления узких мест в производительности БД (медленных запросов) с целью последующей оптимизации.

## 🛠 Решаемая задача
В высоконагруженных системах важно отслеживать запросы, которые выполняются слишком долго и блокируют ресурсы. Эта утилита парсит стандартный лог PostgreSQL (`log_min_duration_statement`) и выводит отчет по самым тяжелым запросам.

## 🚀 Возможности
*   Чтение и парсинг лог-файлов PostgreSQL (работает через регулярные выражения).
*   Фильтрация запросов по заданному порогу времени (в миллисекундах).
*   Сортировка найденных запросов от самых долгих к менее долгим.
*   Группировка статистики по базам данных.
*   Обработка ошибок (файл не найден, нет прав на чтение).

## 📦 Использование

1. Клонируйте репозиторий:
   bash
   git clone https://github.com/yourusername/pg-slow-log-parser.git
   cd pg-slow-log-parser

2.  Запустите скрипт на тестовом логе:

    bash
    python3 parser.py example_pg.log -t 500
    

3. Запуск на реальном логе:

    bash
    python3 parser.py /var/log/postgresql/postgresql-15-main.log -t 1000
